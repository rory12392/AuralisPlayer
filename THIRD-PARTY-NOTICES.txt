AuralisPlayer - Third-Party Notices
===================================

This file lists the third-party software and assets distributed with the
AuralisPlayer Windows packages (portable zip and installer), their licenses,
and where to obtain their source code. Full license texts are in the
"licenses" folder next to this file, or at the end of this file.


1. Distribution terms of this package
-------------------------------------

AuralisPlayer is licensed under the GNU General Public License, version 3
only (GPL-3.0-only; full text in LICENSE). This package is distributed as
a whole under GPLv3. The third-party components listed in section 3 remain
under their own licenses, all of which allow distribution together with

This package includes the official ASIO® output plugin, preinstalled in
plugins\AuralisAsio\ (AuralisAsio.dll and plugin.json). ASIO is a
registered trademark of Steinberg Media Technologies GmbH. The plugin
contains the ASIO SDK 2.3.4, used under GPLv3 (see section 3.9). The ASIO
SDK is compiled into AuralisAsio.dll only; AuralisPlayer.exe does not
contain it. The same plugin is also offered as a separate package
(AuralisPlayer-<version>-plugin-asio-win64.zip) for reinstalling it.

The ASIO Compatible logo files in plugins\AuralisAsio\ (logo-dark.svg,
logo-light.svg) are trademark artwork of Steinberg Media Technologies
GmbH, taken unmodified from the ASIO SDK 2.3.4. They are NOT covered by
GPLv3 and may only be used as described in the "Steinberg ASIO Usage
Guidelines" that come with the ASIO SDK (see
plugins\AuralisAsio\ASIO-LOGO-README.txt).

Source code. The following are offered as attachments on the Release page
of
  https://github.com/rory12392/AuralisPlayer/releases
next to the download of this package:
  a) the AuralisPlayer source code at the exact commit this package was
     built from, including the build and packaging scripts
     (CMakeLists.txt, CMakePresets.json, vcpkg.json with its
     builtin-baseline, the cmake/ folder and the installer scripts);
  b) the source code of each third-party component at the exact version
     listed in section 3, together with the vcpkg port files (portfile
     and patches) used to build it.
The Release page names the commit this package was built from. The
publisher of this package keeps these source archives available for as
long as this package is offered for download; the upstream links in
section 3 are for reference only.

The libraries below are dynamically linked DLLs. You may replace any of them
with a modified, interface-compatible version.
