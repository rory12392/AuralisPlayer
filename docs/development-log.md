# 開發日誌

最新的在最上面。

## 1.0.0（2026-11-18，PRD v1.8）

第一個正式版本：完成 MVP（US-01–US-19）。以下是各里程碑累積到這一版的內容摘要；各里程碑的細節保留在下方原本的段落。

- 新增：播放常見無損與有損格式、CUE 分軌、無縫播放（US-01、US-05、US-07）；WASAPI 獨占位元完美輸出與共享模式，播放列直接切換輸出、音量控制（100% 時維持位元完美）、「停止」按鈕會釋放輸出裝置（US-02）；ASIO 輸出（US-03）；DSF／DFF 播放，DoP、ASIO 原生 DSD、轉 PCM 三種方式（US-04）；ReplayGain 與 R128 計算（US-06）。
- 新增：音樂庫掃描與監看（US-08）；專輯、藝人、資料夾、所有曲目四種瀏覽、即時搜尋與篩選（US-09、US-10）；播放佇列與播放清單，匯入 m3u／m3u8／pls 與 foobar2000 的 .fpl、匯出 .m3u8（US-11–US-14）。
- 新增：同步歌詞（本機 .lrc、內嵌、LRCLIB 自動查詢，可關閉）與全螢幕正在播放（US-15–US-17）；Windows 系統媒體控制（US-18）；深色與淺色主題（US-19）。
- 新增：外掛管理（設定頁「外掛」：檢視、停用、匯入）；ASIO 改成官方外掛並預先安裝，設定 ASIO 的畫面顯示 ASIO Compatible 標誌（US-03，AC-03-0）。
- 新增：發佈形式有安裝檔（只裝給目前使用者、不需要系統管理員）與免安裝 zip；授權檔隨包附上。
- 改善：關閉程式時各模組會等自己的背景工作結束，不再有關閉時偶發碰到已釋放資源的風險；歌詞查詢在 LRCLIB 限流時照 `Retry-After` 暫停（US-16）。
- 決策：整個專案改用 GPL-3.0-only（原本是 MIT），ASIO SDK 採用其 GPLv3 授權選項；發佈包不附 Microsoft 的 D3D 編譯器與 Visual C++ 可轉散發套件（需要另外安裝執行階段）。
- 已知限制：只在 Windows 11 驗證過；沒有數位簽章（SmartScreen 會提示）；第三方外掛還沒開放；.cue 與音檔分開放時不分軌；DSD 播放不能調音量。

## 1.0.0 之前的里程碑紀錄

- 新增（M-04 播放清單）：建立、改名、刪除播放清單，從音樂庫拖曳或右鍵「加入播放清單」，播放清單頁可以播放、拖曳或 Ctrl＋↑／↓ 排序、Delete 移除後復原（US-11）；匯入 m3u／m3u8／pls（含只寫一行 .cue 的整張 CUE）與 foobar2000 的 .fpl，找不到的檔案列出原因並可以「重新對應資料夾」，掃描完成後自動重新檢查（US-12、US-13）；匯出 .m3u8，可選絕對或相對路徑（US-14）；把播放清單檔拖進視窗或在命令列開啟就匯入。
- 決策：播放清單裡的網路路徑、裝置名稱、含控制字元或經過符號連結／junction 的路徑一律不開啟、不播放，只照原文保留並標「找不到」；`#EXTINF` 的標題不保存，找不到的曲目用檔名顯示（US-12、US-13）。
- 驗收：MVP 整合驗收通過（2026-11-17）：真實音樂庫約 1.9 萬首首次掃描 44.6 秒；foobar2000 的兩份清單各 40 首全部對上；WASAPI 獨占與 ASIO 播放 FLAC、WAV、DSF，DAC 顯示的格式相符；全螢幕同步歌詞。
- 已知限制：.cue 和音檔放在不同資料夾時不會分軌（音檔照常以整檔收錄），一軌一檔的這類 .cue 在掃描報告寫成「長度不是正數」；內嵌 cuesheet 的 .fpl 項目沒有實際樣本驗證；4 萬首的播放清單重新檢查約 11 秒（背景執行）。

- 新增（M-03 進階輸出）：ASIO 輸出（US-03）；播放 DSF 與 DFF（DSD64／128／256），DSD 輸出方式可選 DoP、ASIO 原生 DSD、轉 PCM 176.4 kHz，播放中切換從原位置繼續，輸出按鈕標示「DSD64（DoP）」等（US-04）；ReplayGain（關閉／音軌／專輯、防止削波），沒有標籤的曲目可以在設定頁計算整個音樂庫的 R128 增益，結果只存在程式的資料庫、不寫音樂檔（US-06）。
- 決策：DSD 預設用 DoP；ASIO 原生 DSD 開不了時提示並自動改送 DoP；DSD 與 PCM 換格式時先送 DSD 靜音，避免爆音（US-04）。
- 已知限制：DSD 播放時（包括轉 PCM）不能調音量、ReplayGain 不作用；轉 PCM 的音量比原生／DoP 小約 6 dB；曲目右鍵選單還沒有「計算 ReplayGain」（等音樂庫瀏覽頁）。

- 新增（M-01 基礎建設與播放核心）：加入音樂資料夾後自動掃描建立音樂庫，之後監看資料夾變動並在啟動時做增量檢查（US-08）；支援 CUE 分軌，含 Shift-JIS 與 Big5 編碼的 .cue（US-07）；用 WASAPI 獨占位元完美播放 PCM 格式，也可以選共享模式，播放列顯示輸出路徑、格式與是否位元完美（US-01、US-02）；同格式無縫播放、換取樣率時自動重開裝置（US-05）；播放佇列、播放列、佇列面板、正在播放面板與封面（US-10、US-11）；把音樂檔或資料夾拖進視窗、或在命令列帶路徑就開始播放，再開一次程式會交給已經開著的那一個（US-11，AC-11-5）；歡迎畫面、設定頁（音樂資料夾、輸出裝置、外觀）、掃描報告；深色與淺色主題跟隨系統（US-19）。
- 修正：播放列進度條點擊與拖曳的落點（US-11）；佇列中的 CUE 曲目可以播放（US-07）。
- 決策：獨占模式開不了時不自動降級成共享模式，顯示原因讓使用者自己選（US-02）；.cue 只開同一個資料夾裡的本機音檔，解碼只開本機檔案與支援的格式，不會因為檔案內容連到網路（US-01、US-07）。
- 已知限制：還沒有音樂庫瀏覽與搜尋頁、DSD 與 ASIO、播放清單、歌詞、系統媒體鍵（之後的里程碑）；沒有音量控制；副檔名和實際格式不符的檔案無法播放；發佈用的 zip 還沒附授權檔，只供開發驗證；效能只在合成的 4 萬首音樂庫量過（首次掃描約 9 秒、增量約 0.2 秒，熱快取），實際音樂庫還沒量。
